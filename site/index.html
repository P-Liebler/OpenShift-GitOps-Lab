03 / SELBST AUSPROBIEREN

Teste einen echten GitOps-Rollout.

01

Website ändern

Öffne gitops-demo/site/index.html in GitHub und ändere die Versionsnummer oder Überschrift.

02

Commit erstellen

Speichere die Datei im Demo-Branch. Der neue ConfigMap-Hash wird beim nächsten Sync verwendet.

03

Argo CD synchronisieren

Klicke in der Argo-CD-Anwendung auf Refresh und Sync. Danach die OpenShift-Route neu laden.
